A one-line cat joke with a setup and a turn that lands: the cat's lap-sit isn't affection, it's sabotage.

## Run it

Requires Node 22.

```sh
node main.ts
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` if unset).
